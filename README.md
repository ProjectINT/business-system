## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

## Порядок решения.

1. Анализ задачи. Создание репозитория, приведения задачи в агенто-читаемый вид.

2. Глубокий анализ данных, проектирование системы.

3. Сетап окружения.
   - supabase
   - nextjs

4. Разработка модуля ипморта CSV в базу данных Supabase с проверкой качества данных и аудитом.
  - разработка схемы базы данных
  - проектирование модуля валидации данных
  - проектирование модуля калькуляций

5. Модуль валидации. 
   - ошибки пересечений, поиск решения для конфликтов
